# PA Program Consultant

Static website for Tommasino Associates LLC — PA program accreditation consulting.

## Stack

- HTML / CSS / JavaScript
- Tailwind CSS (CDN)
- AOS animations

## Run locally

```bash
python3 -m http.server 8765
```

Open [http://127.0.0.1:8765](http://127.0.0.1:8765)

```
├── index.html
├── css/styles.css

```
